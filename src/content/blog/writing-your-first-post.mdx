## Front matter fields

| Field | What it does |
| --- | --- |
| `title`, `description` | Page heading and search-engine snippet |
| `slug` | The URL: `/blog/<slug>/` |
| `publishedDate` | Sort order and the date shown on cards |
| `draft: true` | Hides the post from the site |
| `index: false` | Adds a `noindex` tag |
| `tags`, `categories` | Create the archive pages under `/tags/` and `/categories/` |
| `heroImage` | Image shown on the post and in link previews |

## Images

All dummy posts use `/images/featured.png`. To use your own picture, put it in
`public/images/` and change `heroImage` to `/images/your-picture.png`. Keep
`heroImageAlt` meaningful: it is read aloud by screen readers.
