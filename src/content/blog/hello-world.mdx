## This is placeholder content

Every post in `src/content/blog/` is a Markdown or MDX file. The block at the
top of the file (between the `---` lines) is the *front matter*: title,
description, date, tags and an image. Everything below it is the article.

## What to do next

1. Copy this file and give the copy a new name, for example `my-first-post.mdx`.
2. Change `title`, `description` and `slug`.
3. Write your text under the front matter.
4. Delete the three example posts when you no longer need them.

Run `pnpm dev` and open `/blog/` to see the result.
