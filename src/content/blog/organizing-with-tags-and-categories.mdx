## Tags and categories

Add a few `tags` to each post and one `categories` entry. The site builds a page
for every value: `/tags/writing/` lists all posts tagged `writing`, and
`/categories/guides/` lists the posts in the `guides` category.

## Naming rules

Write tags and categories in lowercase with hyphens (`getting-started`, not
`Getting Started`). The value is used as it is in the URL.

## Turning them off

Both are on by default. Set `enabled: false` for `tags` or `categories` in
`src/config/pages.mjs` if you do not need them.
